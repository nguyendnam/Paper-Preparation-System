# Paper Preparation System

A software solution supporting research groups
in preparing scientific papers for conference submission.

## Technology Stack

- React
- TypeScript
- Vite
- NestJS
- PostgreSQL
- Prisma
- pnpm Monorepo

## Main Business Objects

- Paper
- Submission Target
- Requirement
- Task
- Evidence
- Verification

## Core Workflows

- Workflow A: Paper Preparation and Submission Readiness
- Workflow B: Submission Target Transfer
